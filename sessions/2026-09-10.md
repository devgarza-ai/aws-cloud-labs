## Key lessons

- Public subnet reachability needs both routing to an internet gateway and a public workload address.
- An S3 gateway endpoint adds private service routing without a NAT gateway.
- RDS still requires deliberate backup and related-resource cleanup.
- Group membership can grant least-privilege access without per-user policy duplication.
- DynamoDB change → stream → Lambda → CloudWatch metric/alarm → SNS is one complete event and observability path.
